# RestFour

Four-bar rest desk for bedroom producers and AI-music finishers.

Generators keep the pocket full. Session players write four live bars of intentional rest — sparse hits, held tones, air — so the full return lands with weight.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight sample CDN pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.

No oscillators. Audio never leaves the tab.

Yesterday’s nearby ships cover crashes, melodies, and finishes. RestFour is the missing held air that gives the next entrance weight.

## Export

Default bounce is 48 kHz, 24-bit stereo.

At 92 BPM and 8 bars the loop file is exactly 1,001,739 samples (`Math.round(8 * 4 * 60 / 92 * 48000)`), first downbeat at sample 0. Tail folded for seamless loop. No random humanize. MIDI alongside, one chair per track.
